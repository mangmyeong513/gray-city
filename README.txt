TXT Reader Lite PWA

실행 방법
1. 이 폴더를 그대로 둡니다.
2. 브라우저에서 file:// 로 열지 말고, 로컬 서버로 엽니다.
3. 가장 쉬운 방법은 아래 둘 중 하나입니다.

Python이 있으면:
python -m http.server 8000

그 다음 브라우저에서:
http://localhost:8000/

특징
- 로컬 서재: TXT를 IndexedDB에 저장
- 설치형 PWA 대응
- 오프라인 캐시
- 표식 필터: **, *, ", '
- 자동 줄바꿈 on/off
- 좌우 터치, 스와이프 페이지 이동
